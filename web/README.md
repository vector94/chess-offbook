# OffBook web

Standalone 3D opening-practice board. Talks only to Lichess's public
Explorer API — no dependency on the `offbook` backend.

## Run

npm install
npm run dev      # dev server
npm test         # unit tests (pure logic only, see docs/superpowers/specs/2026-09-19-3d-opening-practice-board-design.md)
npm run build    # production build
